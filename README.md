# Nexora Interiors — Full-stack website starter

A premium Next.js + TypeScript + Tailwind CSS interior design website for Nexora Interiors, Tirunelveli.

## Run locally
1. Install Node.js 18.17+.
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000`

## Included
- Premium responsive design system
- Home, About, Services, Service detail, Projects, Project detail, Process, Blog, Article, Contact, Consultation
- Responsive navigation
- Framer Motion reveal animations
- Project filtering
- WhatsApp CTA using +91 63856 66794
- SEO metadata, sitemap and robots
- Accessible labels/semantic structure
- Contact API starter endpoint
